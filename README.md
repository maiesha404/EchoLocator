EchoLocator
Real-Time AI Shield Against Voice Scams

Problem
AI-powered voice scams are rapidly increasing, especially impersonation and emergency scams.  
People fall victim because they are emotionally pressured and cannot verify calls instantly.

Solution
EchoLocator is an always-on AI system that detects suspicious calls in real time.  
It runs in the background and provides live risk alerts during calls — no user action required.

How It Works
Call starts  
→ Background service activates  
→ Audio analyzed in small chunks  
→ AI evaluates multiple signals  
→ Live risk score shown  

Detection Approach
EchoLocator analyzes 4 key layers:

- Environmental: background noise, echo, call quality  
- Voice: pitch, breathing, human vs synthetic traits  
- Temporal: pauses, rhythm, response timing  
- Behavioral (USP): urgency, scripted speech, emotional mismatch  

Output
- Safe  
- Suspicious  
- High Risk
